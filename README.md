# 🌐 HTML Mini Projects Collection

Welcome to the **HTML Mini Projects Collection**! This repository contains three distinct beginner-friendly web projects built entirely with **Pure HTML5**. These projects demonstrate the fundamental concepts of web development, including page structuring, text formatting, tables, and web forms.

## 📁 Projects Overview

### Project 1: Movie Review Page (Inception) 🎬
A detailed movie review page dedicated to the movie *Inception*. 
* **Key Features:** Uses semantic HTML, headings, ordered/unordered lists, blockquotes, and a basic user review form.
* **Concepts Covered:** `<q>`, `<blockquote>`, `<cite>`, `<meter>`, `<mark>`, `<form>`

### Project 2: Software & Technology Dictionary 💻
A mini-dictionary explaining basic web technologies (HTML, CSS, JS) and their learning difficulties.
* **Key Features:** Showcases HTML text formatting tags, code snippets, and contact information blocks.
* **Concepts Covered:** `<abbr>`, `<pre>`, `<code>`, `<del>`, `<ins>`, `<sup>`, `<address>`

### Project 3: Order Invoice & Checkout Form 🛒
A realistic e-commerce order summary and payment form screen.
* **Key Features:** Complex HTML tables for invoice data and a comprehensive checkout form with required fields.
* **Concepts Covered:** `<table>`, `<thead>`, `<tbody>`, form inputs (`text`, `radio`, `textarea`), `<var>`, `<del>`, `<ins>`

## 🛠️ Technologies Used
* **HTML5:** 100% of the codebase. No external CSS or JavaScript frameworks were used, highlighting the raw power and structure of standard HTML.
